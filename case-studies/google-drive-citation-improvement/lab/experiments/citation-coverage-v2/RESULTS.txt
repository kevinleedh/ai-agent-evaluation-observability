DRIVE CLAIM / QUOTE COVERAGE: RESULTS

QUESTION
Scoping claims to requested facts avoids unrelated claims with weak citations while preserving explicit relationship answers.

METHOD
Fresh final-answer generations at a reconstructed checkpoint with frozen evidence; no live Drive requests.
7 cases; 42 freshly generated answers; one prompt block differs.
Both variants used the same frozen evidence, model settings, code checks and per-claim judge.
Baseline source: lab/experiments/citation-coverage-v1/candidate.txt
Changed variable: Only the relevance and no-unrelated-filler block; both prompts already contain the citation-coverage instruction.
These are new trials, independently generated for both variants.

INTERPRETATION
The revised prompt has a higher observed combined pass count in this exploratory suite.
Counts are judge decisions, not independently confirmed production accuracy.
Inspect every flagged claim and its attached quotes. Quote support and factual completion are separate.
An empty answer cannot win by avoiding citations when requested supported facts are missing.

FLAGGED ANSWERS
baseline r2 venue_not_in_documents: The answer correctly leaves the venue unresolved because none of the successful reads name a launch location, but the sole attached quote is only about the date and precedence and does not support that absence claim. Citation failure does not overturn task success.
baseline r3 owner_read_failed: The requested launch date is correctly stated and the unknown launch owner is explicitly left unresolved from the failed responsibilities read and successful approval text. Grounding fails solely because the supersession claim\u2019s attached quote does not establish the November 20 date.

REFERENCE CHECKS
The actual role-citation defect was isolated from a separate disputed precedence clause.
Seven reference checks passed before any A/B answers were generated. Earlier disagreements
and the evaluator clarification are retained in the audit files. Neither answer prompt nor
the study evidence dataset was changed by those evaluator preflight repairs.

LIMITS
Exploratory hand-selected synthetic-document cases, same-model judge, no independent held-out set. Refined evaluator is shared by both fresh variants; do not compare its pass rate directly with the previous study.
No model training, live Drive integration test, or independent human adjudication was performed.
